# TechSec · Anti-Zero

A portfolio concept: a scroll-driven 3D landing page for a fictional zero-day protection product.
Everything on the page (company, product, figures, attacks) is made up.

- Three.js (r128) 3D lock and virus, GSAP + ScrollTrigger scroll story
- Interactive "Launch an attack" demo with optional synthesized sound
- Plain static files, no build step. Libraries are bundled in `libs/`.

## Run locally
Open `index.html` in a browser, or serve the folder: `python3 -m http.server`

## Deploy (GitHub Pages)
Settings → Pages → Deploy from branch → `main` / root.
